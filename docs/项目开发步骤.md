## 阶段四：场景切换过渡效果（2026-08-19）

### 提交记录

| 提交 | 说明 |
|---|---|
| `18e5c90` | feat: 添加场景切换过渡效果 |

### 具体工作内容

1. **新增全局过渡管理器 `Transiton`**（自动加载节点）：
   - `Autoloads/transiton.tscn` + `transiton.gd`：封装 `transition_to(scene_path)` 方法
   - 流程：Tween 将 `progress` 参数过渡到 1.0 → 等待完成 → 切换场景 → 再过渡回 0.0，实现"先盖住画面再切换"的效果
2. **实现钻石网格过渡着色器**：`Shaders/transiton.gdshader`（17 行），切换时呈现钻石形状网格展开的视觉特效。
3. **接入主菜单**：播放按钮改为调用 `Transiton.transition_to()` 进行场景切换。
4. **新增角色选择场景**：`Scenes/CharacterSelection/character_selection.tscn`（占位场景，作为播放按钮的目标场景）。
5. **解决的问题**：消除场景切换的突兀感，提升游戏整体质感。

## 阶段五：全局设置节点与音频总线（2026-08-19）

### 提交记录

| 提交 | 说明 |
|---|---|
| `96f0039` | feat: 实现主菜单设置功能与全局自动加载 |

### 具体工作内容

1. **新增全局自动加载节点 `Global`**（`Autoloads/global.gd`）：
   - 定义设置字典 `settings`：`music`（音乐开关）、`sfx`（音效开关）、`fullscreen`（全屏开关），均默认为 `true`
2. **配置音频总线布局**：`default_bus_layout.tres` 将总线拆分为 **Master / Music / SFX** 三条，实现音乐与音效的独立控制。

   - 新增 `update_audio_bus()` 方法：通过 `AudioServer.set_bus_mute()` 实时静音/取消静音对应总线，并更新标签文本（ON/OFF）
   - 新增 `update_fullscreen()` 方法：通过 `DisplayServer.window_set_mode()` 切换全屏/窗口化，并更新标签文本
   - 为每个按钮接入 **UI 点击音效**（`ui_sound.play()`）
   - 设置按钮逻辑全部实现：音乐开关、音效开关、窗口模式、返回
4. **配置默认全屏启动**：项目启动时以全屏模式运行。
5. **解决的问题**：主菜单设置从"空回调"变为真正可用的功能，玩家可实时调节游戏音画。

## 阶段六：存档功能与背景音乐（2026-08-19）

### 提交记录

| 提交 | 说明 |
|---|---|
| `299f174` | feat: 添加存档功能与背景音乐自动播放，调整窗口模式 |

### 具体工作内容

1. **新增背景音乐节点 `Music`**（`Autoloads/music.tscn`）：
   - 使用 `AudioStreamPlayer` 播放 Bg Music.mp3，`autoplay = true` 自动播放
   - 音量 `volume_db = -15`，输出到 Music 总线
   - 注册为自动加载节点，全局持续播放
2. **窗口模式调整**：将项目启动模式从全屏改为**窗口化**。
3. **实现设置存档系统**（`global.gd` 扩展至 36 行）：
   - `save_data()`：将 `settings` 序列化为 JSON，写入 `user://save.json`
   - `load_data()`：检查文件存在性 → 读取 JSON → 解析为 Dictionary → 回填 `settings`
4. **主菜单接入存档**（`main_menu.gd`）：
   - `_ready()` 中初始化时调用 `load_data()`，恢复上次保存的设置（含音频状态、全屏状态同步更新）
   - 退出按钮及窗口关闭时调用 `save_data()` 自动保存
5. **修复问题**：
   - 修复设置按钮的状态更新逻辑（避免 UI 显示与真实状态不同步）
   - 调整窗口切换逻辑，窗口关闭时自动保存设置
6. **解决的问题**：玩家的音画设置可持久化保存，游戏重启后自动恢复；背景音乐全局自动播放。

## 当前项目结构

```
my-topdown-game/
├── Autoloads/                 # 全局自动加载节点
│   ├── global.gd              # 全局设置存储 + 存档/读档
│   ├── music.tscn             # 背景音乐播放器
│   └── transiton.gd/.tscn     # 场景切换过渡管理器
├── Scenes/
│   ├── UI/main_menu.*         # 主菜单（播放/设置/退出）
│   └── CharacterSelection/    # 角色选择场景（占位）
├── Shaders/
│   ├── background.gdshader    # 主菜单背景着色器
│   └── transiton.gdshader     # 钻石网格切换过渡着色器
├── Sounds/                    # BGM + 各类音效素材
├── Font/ + Extra/             # 字体资源
├── Sprites/                   # 完整游戏素材包
├── default_bus_layout.tres    # Master/Music/SFX 音频总线
└── project.godot              # 项目配置
```
